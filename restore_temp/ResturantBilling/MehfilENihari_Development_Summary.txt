───────────────────────────────────────────────────────────────
  1. USER PROFILE & PRACTICAL BACKGROUND
───────────────────────────────────────────────────────────────

The owner runs a single-location Nihari restaurant with a focus on
simple, reliable cashier workflows. Key operational realities:

• Staff are cashiers with minimal tech experience — every screen
  must be tap-friendly with large buttons and zero complexity.

• No complex cash drawer systems. The owner counts cash manually
  at closing using a straightforward "Cash in Hand + Coins" entry.
  The app reconciles this against the day's sales automatically.

• WhatsApp (Baileys) runs as a background service ONLY during
  peak business hours: 5 PM – 11 PM IST. Outside these hours,
  the service sleeps completely — no QR codes, no connections,
  no visible activity. Any messages generated outside the window
  are queued silently and dispatched when the window reopens.

• The owner requires local + cloud redundancy: IndexedDB as the
  always-available local fallback, Firebase/Firestore for
  real-time multi-device sync (desktop + phones), and manual
  JSON backup to Drive E for emergency restore.

• Quarterly GST compliance is handled by auto-generating a
  formatted report and sending it via WhatsApp to up to two
  CA office numbers in a single click.

B. END-OF-DAY CLOSING SHEET
   • eodClosing.js — sales breakdown, reconciliation logic
   • EODClosing.jsx — simple 3-field form:
       - Cash in Hand (notes)
       - Total Coins
       - UPI Amount Collected (pre-filled from actual UPI sales)
   • Live reconciliation: shows balanced / excess / shortage
   • Saves verified closing record to IndexedDB (dailyClosing store)
   • Already-closed days show "✅ Closed" badge, can re-edit

C. QUARTERLY CA WHATSAPP REPORT DISPATCHER
   • caDispatcher.js — quarter detection, report builder, WhatsApp send
   • CADispatcher.jsx — owner-protected UI with:
       - Up to 2 CA office contacts (name + WhatsApp number)
       - Quarter selector (Q1–Q4)
       - Auto-generates: Sales, GST @5% (CGST+SGST), Expenses,
         Category breakdown, Top 10 items, Net Profit
       - "Send to Both CA Offices" — opens WhatsApp for both numbers
       - Auto-marks as sent to prevent duplicate alerts
   • Quarterly "Report Due" alert when current quarter not yet sent

D. BAILEYS SCHEDULED BACKGROUND WHATSAPP ENGINE
   • whatsapp-server/index.js — Express + @whiskeysockets/baileys
   • Time-window: 5 PM (17:00) – 11 PM (23:00) IST only
   • Outside window: service sleeps, messages queued silently
   • Queue processor runs every 60 seconds, auto-dispatches at 5 PM
   • REST API on port 5180:
       - /api/status — connection status, time window, stats
       - /api/qr — QR code for WhatsApp linking
       - /api/send — send message (auto-queues outside window)
       - /api/send-bill — formatted bill notification
       - /api/process-queue — force-process queued messages
       - /api/log — sent message history
   • whatsappClient.js — frontend API wrapper
   • WhatsAppStatus.jsx — owner-protected status UI with:
       - QR code display for linking
       - Connect / Disconnect / Refresh buttons
       - Sent/Failed/Queued stats
       - Recent message log
       - Manual send form
   • package.json scripts: dev:wa, dev:all
